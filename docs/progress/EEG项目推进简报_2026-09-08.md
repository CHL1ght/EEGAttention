## 已落实的数据口径

| 项目 | 结果 |
|---|---|
| 新录制标签 | 一个文件只对应一种状态；文件名 + `session_manifest.csv` 是标签真值，不依赖 marker |
| 二分类标签 | `focus` 与 `unfocus` |
| 静息态 | `death` 统一记为 `rest`，只作基线/质量检查 |
| Legacy 训练候选 | `multiclass_10min` 中 `focus → focus`，`iu + ou → unfocus`；`mixed_20min` 增加 9 个 EDF × 2 个固定片段；`daze` 排除二分类 |
| 旧混合数据 | 采用较晚且实际运行过的专项 Notebook：`0–600 s=unfocus`、`600–1200 s=focus`；保留与早期讲解稿相反的来源冲突说明 |
| mixed 保存方式 | 不物理切割 EDF；同一路径用两行清单分别描述两个逻辑片段，原文件和 SHA-256 保持不变 |
| 窗口 | 4 秒窗、2 秒步长；只保留完整窗口 |
| 活动时间误差 | 新数据每段首尾默认各丢弃 30 秒；准确起止时间可在清单逐行覆盖 |
| 通道与采样 | 当前设备记录均为 300 Hz、26 路信号；实际建模通道由冻结配置确定 |
| 防泄漏 | 先按完整 `session_group_id` 划分，再切窗；同一 mixed EDF 的两个片段不得分到两侧；LOCKED_TEST 禁止训练和调参 |
