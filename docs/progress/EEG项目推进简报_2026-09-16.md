# EEG 项目推进简报｜2026-09-16

## 本阶段结论

New Paradigm v1 已完成首批 lyc 数据登记、单日 first pass、observe prediction-only 和 frozen model 的 historical gaming replay。模型在当天数据上的区分很强，但当前证据仍是**单日 exploratory**：二分类录制顺序为 `F-F-F → U-U-U`，label 与 recording order 完全混杂，不能解释为跨日 attention 或 task engagement 泛化。

当前研究重点由“继续刷准确率”转为：**confound audit + cross-day validation + task engagement construct validation**。

## 1. New Paradigm v1 首批数据

2026-09-16 首批 lyc 共 7 条真实 session：

- focus ×3
- unfocus ×3
- observe ×1（认真观战王者、减少主动手部操作；reference/control）

`focus` / `unfocus` 继续作为当前实验操作标签；`observe` 不进入二分类 fit、model selection 或 accuracy。既有 session 没有因模型结果重标或重命名。

## 2. 单日 6-session LOSO

仅使用 3 条 focus 与 3 条 unfocus，以完整 session 做 leave-one-session-out：

| 指标 | 结果 |
|---|---:|
| session majority | 6/6 |
| session accuracy | 100.00% |
| window accuracy | 98.07% |
| window balanced accuracy | 98.16% |
| held-out windows | 1,656 |

结果很强，但三条 focus 全部先录，随后才是三条 unfocus，即 `F-F-F → U-U-U`。因此时间漂移、疲劳、设备/电极变化或其他 session drift 都可能贡献区分；6-session LOSO 仍在同一 recording day 内，不能消除 day/order confound。

## 3. Observe prediction-only

Observe session 未参与 fit、模型选择或准确率计算：

- 280 个 windows 中 274 个预测为 unfocus，即 **97.86% windows → unfocus**。
- session majority 为 unfocus。
- 该结果是运动/操作混杂的第一条 reference，不足以独立证明模型识别主动 engagement；后续还需要“有手部操作但认知投入低”的预先设计 control。

## 4. Frozen model 与 historical replay

Frozen model SHA256：`2b7b97f9f2399bcd3595df63a406fd66adfb470edc7f9390d8d67d45431d8e24`。

Historical replay 严格 prediction-only，`fit_calls=0`，没有 calibration、阈值调整、重标或模型更新：

- 7 条明确记录为“认真/高度集中打王者”的历史 session，session majority 全部为 focus。
- 这 7 条的 window-weighted focus proportion 约 **84.51%**。
- 但 7 月 legacy gaming 多数被该模型判为 unfocus，而 9 月明确认真打王者的 session 明显偏 focus，显示巨大 source/date drift。
- 因此 historical label 不保证与 New Paradigm v1 语义等价，本回放不是独立 final test，也不能替代跨日预注册验证。

## 5. 研究构念与控制路线

当前核心研究构念明确为 **task engagement / cognitive engagement（任务认知投入状态）**：未来面向工作/学习场景，以时间轴估计用户是否持续、主动地投入当前任务。

- 不把目标简化为游戏 focus/unfocus 分类，也不直接预测工作效率、正确率或反应速度。
- 正确率、反应时间、任务完成量等可作为未来 external validation，但不是唯一标签定义。
- flow 只作为未来可能研究的高投入状态；当前 `focus` 不等于已验证 flow。
- 不做所有混杂变量的全因子组合，采用假设驱动的 control ladder，一次优先攻击一个最大混杂，其余条件尽量固定。

控制优先级：

1. C1：跨日 + 顺序随机化。
2. C2：motor confound。
3. C3：active vs passive engagement。
4. C4：cross-task。
5. C5：fatigue、sleepiness、mood、stress、arousal 等内部状态。

完整路线见 [ENGAGEMENT_CONTROL_ROADMAP](../current/ENGAGEMENT_CONTROL_ROADMAP.md)。

## 6. 下一次采集

下一 recording day 在录制前预先确定交错/随机顺序，例如 `U-F-U-F-F-U`。开始录制后不能根据模型预测调整顺序；设备、佩戴流程、姿势、场地、任务版本、session 时长和间隔尽量固定，偏差如实记录。

Day 2 的 session 清单、条件、顺序和用途必须在首次预测前冻结。随后只加载 frozen 2026-09-16 model 做 prediction-only，不 fit、不校准、不调阈值、不筛选或重标 session。有两个 recording day 后执行 leave-one-day-out。

## 7. 记录结构与产品方向

新增空白 `control_experiment_log_template.csv`，只含 header。它通过 `session_id` 关联 manifest，补充 planned/actual condition、recording order、task family、motor、active/passive、内部状态和环境/佩戴异常。

`session_manifest.csv` schema 未修改，继续是 canonical label、任务、数据角色、路径、区间和哈希的权威来源。fatigue、sleepiness、mood、arousal 等属于 **confound metadata / auxiliary measures**，不是模型标签真值。

下一系统开发方向为 **Attention Dashboard**：未来展示 engagement 状态时间轴。Dashboard 不改变当前单日证据边界，开发与构念验证应并行但结论保持保守。
