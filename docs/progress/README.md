# 这个目录是什么

这里按日期保留项目推进简报，让读者看到当时做了什么决定。

## 它属于项目哪一步

Stage 1–8：按日期保存多个阶段的决策，而非只属于现场反馈。

前一步：每轮实验已有事实与产物。
这一步：记录当时的证据、问题和下一步。
后一步：新阶段另写记录，不覆盖旧报告。

完整故事：[实验阶段地图](../EXPERIMENT_MAP.md)；模型解释：[模型字典](../MODEL_CATALOG.md)。

## 为什么会有这个目录

避免用今天的判断覆盖过去的实验状态；新状态由项目地图和本轮说明给出。

## 输入从哪里来

每个阶段已保存的报告、配置和人工记录。

## 谁生成这里的文件

人工撰写，按TEMPLATE.md组织；本轮不改旧实验分数。
